# DevOps Operations Handbook

Sample documentation built from Markdown and published through GitHub Actions.

**Version: 1.**

## Delivery Workflow

1. Propose changes through a pull request.
2. Pylint checks the Python code, and MkDocs checks the documentation.
3. After the merge to `main`, MkDocs builds the static site.
4. GitHub Pages publishes the build artifact.

Site URL: `https://veosp.github.io/devops-docs/`.
