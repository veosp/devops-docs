# devops-docs

Practice 9 repository for Pylint, MkDocs, GitHub Actions, and GitHub Pages.

- Documentation source: `docs/`
- MkDocs configuration: `mkdocs.yml`
- CI workflow: `.github/workflows/quality.yml`
- Publication workflow: `.github/workflows/pages.yml`

MkDocs generates `site/` during the build. Git ignores that directory.
